# Cyber Security Journey - تطبيق رحلة الأمن السيبراني

تطبيق React حديث ومتطور لتعلم الأمن السيبراني بطريقة منظمة ومتسلسلة.

## 🎯 المميزات

### ✨ تصميم موحد ومتسق
- **نظام ألوان موحد** في جميع الصفحات
- **حركات وتأثيرات متناسقة** باستخدام Framer Motion
- **دعم الوضع المظلم** والفاتح
- **تصميم متجاوب** لجميع الأجهزة

### 📚 إدارة المحتوى
- **الصفحة الرئيسية** - نظرة عامة على التقدم والمراحل
- **صفحة اليوم** - عرض مهام اليوم والمراجع
- **صفحة الملاحظات** - إدارة الملاحظات الشخصية
- **صفحة المدونة** - كتابة وتتبع رحلة التعلم
- **صفحة التقدم** - إحصائيات وإنجازات مفصلة
- **صفحة الإعدادات** - تخصيص التجربة

### 🛠️ المكونات الموحدة
- **PageLayout** - تخطيط موحد لجميع الصفحات
- **Card** - كروت قابلة لإعادة الاستخدام
- **Button** - أزرار موحدة بأنواع مختلفة
- **Modal** - نوافذ منبثقة موحدة
- **RichTextEditor** - محرر نصوص غني
- **PhaseCard** - عرض المراحل
- **TaskCard** - عرض المهام

## 🔧 التخصيص

### إضافة صفحة جديدة
1. أنشئ ملف في `src/pages/`
2. استخدم `PageLayout` كقالب أساسي
3. استخدم المكونات الموحدة من `src/components/ui/`
4. أضف النصوص المترجمة في `src/hooks/useLocalization.ts`

### تخصيص الألوان
عدّل ملف `src/constants/theme.ts` لتغيير:
- الألوان الرئيسية
- التدرجات اللونية
- الظلال والزوايا
- الحركات والتأثيرات

## 🌐 الترجمة
