# CyberPlan - خطة تعلم الأمن السيبراني

تطبيق React متقدم لتعلم الأمن السيبراني مع نظام إدارة المهام واليوميات والتقدم.

## 🏗️ هيكل المشروع

```
src/
├── components/          # المكونات القابلة لإعادة الاستخدام
│   ├── ui/             # مكونات واجهة المستخدم الأساسية
│   ├── layout/         # مكونات التخطيط
│   ├── dashboard/      # مكونات لوحة التحكم
│   ├── journal/        # مكونات اليوميات
│   ├── notebook/       # مكونات المفكرة
│   ├── plan/           # مكونات الخطة
│   └── charts/         # مكونات الرسوم البيانية
├── pages/              # صفحات التطبيق
│   ├── DayView/        # صفحة عرض اليوم
│   │   ├── DayViewPage.jsx    # الصفحة الرئيسية
│   │   ├── TaskItem.jsx       # عنصر المهمة
│   │   ├── NotesPrompt.jsx    # تلميحات الملاحظات
│   │   └── TiptapJournalEditor.jsx # محرر اليوميات
│   ├── Dashboard.jsx   # لوحة التحكم
│   ├── CyberPlan.jsx   # الخطة الرئيسية
│   ├── Journal.jsx     # اليوميات
│   ├── Notebook.jsx    # المفكرة
│   ├── WeekView.jsx    # عرض الأسبوع
│   ├── PhaseView.jsx   # عرض المرحلة
│   └── Settings.jsx    # الإعدادات
├── context/            # إدارة الحالة العامة
│   └── AppContext.jsx  # السياق الرئيسي للتطبيق
├── services/           # الخدمات
│   ├── dbService.js    # خدمة قاعدة البيانات
│   └── dataService.js  # خدمة البيانات
├── hooks/              # Hooks مخصصة
├── utils/              # أدوات مساعدة
├── i18n/               # الترجمة
├── layouts/            # تخطيطات الصفحات
└── assets/             # الملفات الثابتة
```

## 🚀 الميزات

- **إدارة المهام**: تتبع تقدم المهام وإنجازها
- **اليوميات**: محرر نصوص متقدم للتدوين
- **المراجع**: إدارة المراجع والروابط
- **التقدم**: تتبع التقدم عبر المراحل والأسابيع
- **الترجمة**: دعم العربية والإنجليزية
- **الوضع المظلم**: تبديل بين الأوضاع الفاتح والمظلم
- **PWA**: تطبيق ويب تقدمي
- **التخزين المحلي**: حفظ البيانات محلياً

## 🛠️ التقنيات المستخدمة

- **React 18** - مكتبة واجهة المستخدم
- **Vite** - أداة البناء
- **Tailwind CSS** - إطار العمل CSS
- **React Router** - التوجيه
- **Zustand** - إدارة الحالة
- **Dexie.js** - قاعدة بيانات IndexedDB
- **Framer Motion** - الرسوم المتحركة
- **TipTap** - محرر النصوص
- **i18next** - الترجمة
- **React Hot Toast** - الإشعارات

## 🎨 الألوان والتصميم

### الألوان:

## 📊 قاعدة البيانات

يستخدم التطبيق IndexedDB عبر Dexie.js لتخزين:
- بيانات الخطة
- التقدم
- الملاحظات
- اليوميات
- الإعدادات

## 🔄 إدارة الحالة

- **AppContext**: الحالة العامة للتطبيق
- **Local Storage**: الإعدادات والتفضيلات
- **IndexedDB**: البيانات الرئيسية
